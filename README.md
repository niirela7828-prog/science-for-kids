# מדענית קטנה 🔬

אפליקציית מדע לילדות בכיתה ב׳: 5 עולמות, 50 פעילויות, ועוזר מעבדה בשם זיקי.
עובדת בלי אינטרנט, בלי חשבונות ובלי פרסומות. כל המידע והתמונות נשארים במכשיר.

| עולם | פעילויות |
|---|---|
| 🧪 מעבדה בבית | 10 ניסויים עם חומרים מהמטבח |
| 🫀 המסע בגוף | 9 איברים, נפתחים לפי הסדר |
| 🔍 בלשית הטבע | 12 משימות בחוץ, ואלבום לפי עונות |
| 🤔 מה קורה אם…? | 9 סימולציות של סיבה ותוצאה |
| 🚀 מסע בחלל | 10 עצירות: השמש, הירח ו-8 כוכבי הלכת |

## למפתחים
```bash
npm install
npm run dev      # הרצה מקומית
npm test         # בדיקות
npm run build    # בנייה לתיקיית dist
```
React + Vite + TypeScript + Tailwind, ‏PWA עם vite-plugin-pwa.
החלטות עיצוב ופירוט איך מוסיפים עולמות נמצאים ב-[DECISIONS.md](DECISIONS.md).

## העלאה ל-GitHub Pages
בכל דחיפה (push) ל-`main`, הקובץ `.github/workflows/deploy.yml` בונה ומפרסם את האפליקציה.
צריך להפעיל פעם אחת: Settings ← Pages ← Source: **GitHub Actions**.
